# ☕ CoffeeHub – Coffee Shop Website

## 🚀 Internship Project – Task 1

This project is a simple static coffee shop website built using HTML and CSS as part of my internship.

---

## 📌 Project Description

CoffeeHub is a responsive static website designed for a coffee shop. It includes multiple sections like Home, About, Menu, and Footer with a clean and modern UI design.

---

## ✨ Features

- Responsive homepage design  
- Navigation bar for easy access  
- Hero section with call-to-action button  
- About section describing the coffee shop  
- Menu section with coffee items  
- Footer with contact and social links  
- Mobile-friendly layout using CSS media queries  

---

## 🛠️ Technologies Used

- HTML5  
- CSS3
